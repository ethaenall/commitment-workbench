# AI-assisted engineering process

AI assistants contributed substantially to implementation, tests, investigation, review, and documentation. This is not presented as unaided human authorship. Upstream Habenula supplies the original governed-agent foundation.

## Development tools are not application dependencies

Development used delegated review, a persistent orchestration environment, isolated source copies, bounded native commands, regression tests, and retained verification receipts. The application implements its own TypeScript/Node/QuickJS workflow. It does not depend on the development-agent harness.

## Evidence and limits

- Distinguish deterministic authored-provider fixtures from live model outcomes.
- Keep failed, interrupted, and unrun benchmark rows visible.
- Require observed local resource settlement before accepting a successful native task.
- Treat source hashes as identities, not independent witnesses or proof of semantic correctness.
- Preserve upstream credit and third-party notices. Prior contributors also reviewed the code; these reviews are not independent of authorship.

Personal development logs, model-account details, token totals, billing information, and hiring-preparation notes are not distributed. Published synthetic results omit observed token usage and provider-account routing. This limits historical reproduction and does not imply zero usage or cost.
